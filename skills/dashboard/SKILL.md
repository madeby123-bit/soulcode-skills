# Marketing-Dashboard

Delegiere an `dashboard`.

## Schritte
1. Lies `~/.claude/marketing/dashboard.md`.
2. Zeig einen kompakten Statusbericht: Nordstern, KPI-Tabelle (Ist/Ziel/Trend), aktuelle Woche & Fokus, Content-Queue, naechste 3-5 Tasks.
3. Neue Zahlen/Fortschritt einarbeiten und Datei aktualisieren.
4. Bei Planbedarf an `strategist` weitergeben.

Visuell, knapp, motivierend, kleines „du“.

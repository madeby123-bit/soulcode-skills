# Funnel-Bau

## Stufen
1. **Top (Aufmerksamkeit):** Reels/Shorts/Ads -> Reichweite.
2. **Middle (Vertrauen):** Wert-Content, Newsletter, Lead-Magnet.
3. **Bottom (Angebot):** Check-up-Call, Verkaufsseite, Kurs/Coaching.
4. **Nachfass:** E-Mail-Sequenz, Retargeting.

Pro Stufe: Ziel, Asset, CTA, Metrik. Zeig den Weg einer Frau vom ersten Reel bis zur Kundin. Zielgruppe: spirituelle Frauen und Coaches. Ton: warm, kleines „du“, Resonanz statt Hype, KEINE Gedankenstriche. Marke, Stimme und Website kommen aus dem jeweiligen Auftrag.

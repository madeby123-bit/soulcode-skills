# Wettbewerbsanalyse

## Schritte
1. 3-5 Vorbilder/Wettbewerberinnen benennen.
2. Pro Konto: Positionierung, Angebot, Content-Stil, was funktioniert (Top-Posts).
3. Luecken finden: was fehlt, was kann Jennifer besser/anders (Geld+Spiritualitaet, KI, Ehrlichkeit).
4. 3 konkrete Differenzierungs-Chancen ableiten.

Optional mit WebSearch reale Konten pruefen. Marke: Soul Marketing (Jennifer Graeser), Zielgruppe spirituelle Frauen/Coaches. Ton: warm, kleines „du“, Resonanz statt Hype, KEINE Gedankenstriche. Website: www.soulcode-marketing.de.

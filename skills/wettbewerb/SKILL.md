# Wettbewerbsanalyse

## Schritte
1. 3-5 Vorbilder/Wettbewerberinnen benennen.
2. Pro Konto: Positionierung, Angebot, Content-Stil, was funktioniert (Top-Posts).
3. Luecken finden: was fehlt, was kann sie besser oder anders (Geld+Spiritualitaet, KI, Ehrlichkeit).
4. 3 konkrete Differenzierungs-Chancen ableiten.

Optional mit WebSearch reale Konten pruefen. Zielgruppe: spirituelle Frauen und Coaches. Ton: warm, kleines „du“, Resonanz statt Hype, KEINE Gedankenstriche. Marke, Stimme und Website kommen aus dem jeweiligen Auftrag.
